# BOSS 悬浮球测试（无功能）

独立测试扩展，版本0.1.0。原投递助手及其记录不受本插件修改。

## 加载

1. Chrome地址栏输入 `chrome://extensions`，打开“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本仓库中的 `floating-probe` 文件夹。
3. 打开新的BOSS页面，或刷新已有BOSS页面（刷新前请先保存未发送内容）。
4. 在 `https://www.zhipin.com/` 页面右侧约中上部看到带“试”字的小球即可。

球没有点击、hover、拖动或侧栏功能，鼠标点击穿透，不拦截页面原有操作。

## 试验边界

- 会向顶层页面新增一个独立DOM宿主，内部用Shadow DOM隔离样式；仍属于修改页面DOM，不是不可检测方案。
- 不修改既有业务节点，不读取公司、职位或聊天，不监听操作、不请求网络、不保存数据、不与原助手通信。
- 无后台脚本，无额外API权限，只在上述BOSS域名注入一次；站点删除宿主时不自动恢复。
- 本试验只能观察这次使用是否出现异常，不能证明BOSS不会检测或以后不会触发限制。
- 若要单独观察这个插件的表现，可先暂时停用原助手，不要卸载或清空其数据；结束后可重新启用。

## 停止与移除

在扩展管理页停用或移除“BOSS 悬浮球测试（无功能）”，再刷新已打开的BOSS页面，让已注入的小球消失。停用扩展本身可能不会立即移除旧页面中的节点。
