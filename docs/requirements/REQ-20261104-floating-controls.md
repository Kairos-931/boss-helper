## 用户明确要求

- 不设置“看”按钮，查看沿用现有自动化行为。
- 鼠标移入提供已沟通标记操作。
- 双击悬浮球直接打开现有完整右侧面板；右侧面板提供单击入口，收回为小悬浮条。
- 当前可靠识别的公司已看过或已沟通时，整个小球变红，作为看过的提醒。
- 完全取消“无合适岗位”功能及按钮，历史草稿标记cancelled。

## 已确认边界

- 查看规则先按用户“跟现在一样”解释为：进入公司详情且唯一身份可靠才自动记录；展开职位只查重，不扩大为职位曝光即自动记录。悬浮层不另加手动查看按钮，原侧栏行为暂不改变。
- 悬停展开精简条，展示公司名、状态与当前可用的“标记已查看/标记已沟通”按钮；点击按钮才写入，单纯移入不写。已沟通展示状态，取消沿用原记录列表。
- 未记录与无法识别必须区分；简称候选不按确定看过变红，不允许按名称猜测写入。
- 历史已看过/已沟通为红色；首次本次自动记录普通色并注明“本次已记录”，下次遇到变红。已沟通优先红色，撤销/未知/简称/列表不伪装历史。
- 正式能力接入原助手，同用公司数据；独立试验插件保留，使用正式版时手动停用试验版。已先修改AGENTS，限定仅新增自有悬浮宿主，不改业务节点。
- 保持Chrome116最低版本；双击消息中同步调用sidePanel.open，保留点击手势；收起先让当前页面固定展示精简条，再调用sidePanel.close（可用时），旧版setOptions停用再恢复同标签侧栏。完整面板仍为原生侧栏。

## 验收草案

1. 历史已看过或已沟通公司整球变红，切换未记录/无法识别公司不残留红色。
2. 移入可操作精简条，移动到条内不消失；点击已沟通保存，失败可重试，不误标其他公司。
3. 双击打开完整侧栏，侧栏单击收回精简条；不因单击/双击竞争重复记录。
4. 公司自动记录、撤销抑制、沟通自动识别和本地记录继续沿用既有约束。
- 本需求已获独立开发确认；尚无GUI、安装、push或代理授权。静态球使用反馈不能替代正式交互验收。
