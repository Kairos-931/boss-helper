# 薪资提示精简与短时失败提示

- Status: awaiting_acceptance
- Priority: medium
- Requirement revision: r1
- Target version: 0.21.1
- Confirmed date: 2026-11-06
- Development started date: 2026-11-06
- Completed date: not completed
- 来源：用户要求删除“4 个历史岗位的薪资待重新采集”提醒；当前岗位未成功时显示原因，但只保留一会，不持续存在。

## 目标与用户价值

- 用户目标：侧栏不再长期挂着旧岗位待重采的聚合提醒；当前岗位失败时仍能知道原因，但提示会自行消失。
- 当前问题：历史待重采数量会持续显示；当前岗位的薪资特殊字体/失败原因也会一直保留，形成干扰。
- 用户可见结果：历史提醒消失；当前岗位原因短暂出现后自动隐藏，成功提示也按原有时效隐藏。

## 范围

### 包含

- 删除侧栏“N 个历史岗位的薪资待重新采集，重新打开对应岗位可更新”聚合提醒。
- 当前采集会话的薪资等待/失败原因在侧栏和悬浮球短暂显示：成功约5秒，失败或等待原因约8秒后自动隐藏。
- 侧栏“重试当前岗位”按钮只在失败原因仍显示时出现，随提示一起隐藏。
- 侧栏提示过期后恢复当前状态文案；运行中显示“正在采集本页显示的岗位”，未运行显示原有开始提示。
- 本轮采用自动隐藏，不新增点击关闭按钮。
- `salaryPending`仍用于状态统计和CSV“待重新采集”标记，不删除旧岗位、不改变薪资判断或采集规则。

### 不包含

- 不删除历史岗位、不清空薪资待重采状态、不自动重抓历史岗位。
- 不改变CSV字段、导出提示、公司记录、话术、看板、权限或网络边界。
- 不新增点击关闭、设置项或持久化“已忽略”状态。

## 用户流程

1. 用户采集一个薪资无法可靠识别的岗位。
2. 侧栏和悬浮球显示失败原因；约8秒后提示自动隐藏，累计/未成功统计仍保留。
3. 侧栏不再因存在历史坏薪资而长期显示“N 个历史岗位待重采”。
4. 用户重新打开同一岗位时，可再次尝试更新；成功提示约5秒后隐藏。

## 数据与安全边界

- 读取：既有session采集会话的`lastAt`、`note`、`error`及`salaryPending`统计。
- 写入：仅既有采集会话的时间和结果字段；不新增公司、岗位、CSV、话术或看板字段。
- 不得做：不因提示隐藏删除岗位资料或改变待重采状态；不新增网络/权限。

## 失败与边界情况

- 失败原因时间缺失或异常：不显示旧原因，避免重新挂出历史错误。
- 提示过期后：统计“未成功”数字继续保留，但不继续显示原因或重试按钮。
- 悬浮球切换回公司视图后：不显示采集提示，不播放或延后公司提示音。

## 验收标准

1. 侧栏不再出现“N 个历史岗位的薪资待重新采集”聚合提醒。
2. 当前岗位薪资等待/失败原因立即显示，约8秒后自动隐藏；成功提示约5秒后隐藏。
3. 侧栏与悬浮球的提示时效一致；侧栏重试按钮随失败提示隐藏。
4. 不删除岗位，不改变CSV“待重新采集”标记、采集规则、权限或网络边界。
