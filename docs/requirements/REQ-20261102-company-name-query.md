## 范围与行为

- 没有可靠公司身份链接时，从当前可确认的公司标题、职位公司区域或当前会话公司标题读取简称。联系人姓名、招聘者身份、相邻卡片和推荐公司不得作为简称。
- 当前会话优先于底层公司页：会话展开时只查询该会话，不能因背景页面有公司链接而记录背景公司。选中会话与会话头部公司不一致时等待更新，不保留旧候选。
- 只在已有公司记录中按名称查询，显示至多三条“可能看过”的候选、原记录名称和首次记录日期。有已沟通标记的候选明确注明是该条历史记录的标记。
- 统一全半角、大小写、空格、标点与常见法定名称后缀；优先相同名称，再匹配简称包含关系；较长名称允许一个字符差异。过短或通用名称不扩大匹配。
- 名称相近不代表同一家公司：不建立身份映射，不自动写入或合并记录，不调用名称纠正。未匹配显示“暂无名称相近的记录”，不宣称从未看过。
- 公司详情页原有可靠身份自动记录、职位主动记录等既有行为保留；本项简称查询、职位查询和会话查询均不新增已查看记录。

- 简称、当前岗位、候选名称正确；会话切换、身份冲突、隐藏或推荐区域不会留下旧公司候选。
- 简称查询零公司记录写入，无法触发已查看/已沟通或修改原记录；候选已有标记仅作为历史记录信息显示。
- 无匹配、没有简称、本地记录读取失败分别反馈；不把错误当没有历史。
- 定向解析/匹配/面板/后台回归，再执行项目 test、check、build。未授权 GUI，不进行真实 Chrome 视觉验收或安装。
