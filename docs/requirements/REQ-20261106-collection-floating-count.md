- 来源：用户要求悬浮球展示采集信息；在“只显示总数、累计总数加本次统计、每次成功提示”三方案中选择方案2。
- Target version: 0.22.1（本次数显示口径修订）
- 关联：REQ-20261106-job-collection-mode/r3、REQ-20261106-dashboard-job-count/r1；当前本地基线0.20.0。

## 目标与用户价值

- 用户目标：采集岗位时不用反复打开侧栏，球体就能看到本次采集了多少；悬停可继续了解累计、本次新增和最近结果。
- 目标用户：在电脑 Chrome 上使用 BOSS 直聘岗位采集的本项目用户。
- 当前问题：0.20.0悬浮球只显示公司记录状态，采集信息仅在侧栏“岗位采集”区。
- 用户可见结果：当前标签页采集运行时，球体显示本次会话成功采集/更新的岗位数；展开后同时显示累计、本次统计和最近一次结果。

## 范围

### 包含

- 当前标签页正在采集时，球体显示本次会话成功采集/更新的岗位数，并使用中性采集样式；不复用公司历史红/绿颜色。
- 悬停条显示“本页采集中”“本次已采集 N 个岗位”“本次新增 A · 更新 B · 未成功 C”“累计 M 个岗位”。
- 最近一次成功或更新显示约5秒：`已采集：岗位名`或`已更新：岗位名`；失败/等待原因约8秒后自动隐藏，不持续保留。
- 采集态隐藏公司名称、公司历史文案、查看/沟通/撤销按钮和公司提示音控件。
- 采集态单击展开悬浮条，不写公司记录；双击打开侧栏；拖拽、位置记忆和左右换边保留。
- 暂停本页采集、结束采集或切换到未开启采集的标签页后，恢复原公司记录视图与交互。
- 后台只向当前顶层读取器提供采集摘要：运行状态、本次成功岗位数、累计去重数、本次新增/更新/未成功、最近岗位名、最近提示/错误及结果时间；不返回岗位链接、描述、薪资、公司关联或话术。
- 为最近结果增加仅存在于`chrome.storage.session`的结果时间，不进入公司记录、岗位记录、CSV或看板。

### 不包含

- 不显示逐条采集历史、岗位列表、筛选、比较、当天新增或薪资分布。
- 不新增采集筛选、批量操作、岗位管理、权限、网络请求、上传或外部服务。
- 不改变岗位去重、CSV字段、公司记录格式、话术、看板或既有公司提示音规则。
- 不在悬浮球显示其他标签页的采集数量；其他标签页采集不改变当前页面的采集视图。

## 用户流程

1. 用户在侧栏点击“开始采集本页”，当前标签页进入采集状态。
2. 悬浮球显示累计采集数；用户不用打开侧栏即可看到总量。
3. 打开并成功采集或更新岗位后，累计数保持去重口径，本次新增/更新数变化，并短暂显示最近结果。
4. 用户悬停悬浮球，查看累计、本次统计和最近一次成功或失败。
5. 用户暂停采集或切换到未开启采集的标签页，悬浮球恢复公司记录状态；拖拽和双击侧栏继续可用。

## 交互说明

- 球体：采集中显示本次会话成功采集/更新的岗位数，样式与公司历史红/绿明确区分；数字为0时正常显示。
- 悬停条：第一行“本页采集中”，第二行“本次已采集 N 个岗位”，第三行本次新增/更新/未成功，第四行累计总数，第五行最近结果。
- 成功反馈：约5秒后隐藏最近成功行，但累计与本次统计继续显示。
- 失败反馈：显示可行动的固定原因，例如“薪资待识别，请重新打开该岗位”；约8秒后自动隐藏，不持续保留。
- 单击：展开或收起悬浮条，不触发公司查看/沟通/撤销。
- 双击：打开侧栏；拖动超过阈值不触发单击或双击。

## 数据与安全边界

- 读取：本标签页`job-capture:<tabId>`采集会话、有效`job:`记录去重总数及会话结果时间。
- 写入：仅采集会话更新最近结果时间；不新增公司记录、岗位记录、CSV、话术或看板字段。
- 消息：沿用当前标签页顶层`FLOAT_STATUS`来源校验；只向该读取器返回采集摘要，不暴露岗位明细。
- 不得做：不读取聊天正文、不触发采集、不自动切换岗位、不修改BOSS业务DOM、不绕过平台验证、不发送公司提示音。

## 失败与边界情况

- 采集摘要读取失败：显示明确的读取失败状态并自动重试，不能显示假0；不把公司历史状态误显示为采集状态。
- 最近结果时间为空或异常：不显示成功提示，但累计和本次统计可继续展示。
- 暂停时悬浮条已展开：立即恢复公司视图，不保留采集按钮或计数。
- 当前页面无法识别公司：采集态仍以当前标签页会话为准；暂停后按原有“无法识别”公司状态显示。

## 验收标准

1. 当前标签页采集运行时，球体显示本次会话成功采集/更新的岗位数，与“导出本次”数量一致；累计总数在悬停条显示。
2. 悬停条显示“本页采集中”、本次数、累计数、本次新增/更新/未成功和最近一次结果；成功提示约5秒后消失，失败/等待原因约8秒后消失。
3. 采集态不显示公司名称、历史、查看/沟通/撤销或提示音控件，不播放公司提示音；单击不写公司数据，拖拽和双击侧栏继续有效。
4. 暂停或切换标签页后恢复公司记录视图，其他标签页采集不串入当前页面。
5. 读取失败不显示假0；不新增权限、网络请求、岗位明细读取或公司/岗位/CSV/话术写入。

## 开发执行建议

- 复杂度：中等；主要风险是采集态与公司态的切换、1.5秒轮询下最近结果的显示时机，以及不误触公司写入。
- 推荐模型：GPT-6.1 Sol / Medium；涉及后台摘要、悬浮球状态机和交互回归，Medium比Low更能降低切换与误写风险，较High节省用量。
- 模型推荐仅供参考，实际沿用用户手动选择，不自动切换。
