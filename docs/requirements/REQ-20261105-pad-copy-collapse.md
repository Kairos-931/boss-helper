# 复制话术后收起侧栏

- Status: awaiting_acceptance
- Requirement revision: r1
- Target version: 0.14.0
- 来源：2026-11-05 用户要求加大“复制话术”按钮，并新增开关；开启后点击复制直接关闭右侧栏、保留页面悬浮条，效果等同“收起为悬浮条”。
- 开发批准：2026-11-05 用户回复“是”，批准已展示范围。沿用当前模型与中等推理，实际模型不自动切换；仅确定性验证，无GUI、安装、push或发布。

## 目标与用户价值

- 用户目标：复制话术后立即腾出右侧空间，同时保留页面上的悬浮入口，减少“复制—再点收起”的重复操作。
- 用户可见结果：话术按钮更醒目；“复制后收起侧栏”开关可独立控制复制后的侧栏行为。

## 已批准范围

- “复制话术”改为更明显的绿色胶囊按钮，增大点击区域与字号，仍保持侧栏内克制尺寸。
- 话术标题右侧新增“复制后收起侧栏”开关，默认关闭。
- 开关开启时，只有剪贴板复制成功且复制文本仍是当前文本，才调用既有“收起为悬浮条”路径：先固定页面悬浮条，再关闭右侧栏。
- 开关关闭时，复制行为与旧版一致，侧栏保持打开。
- 复制失败、复制期间文本被修改或开关未成功保存时，不收起侧栏，并给出可继续操作的状态。
- 收起失败沿用既有“重新读取并收起”恢复流程；不经由自动刷新、自动注入或新增权限绕过。
- 开关状态保存在独立本机设置键 `settings:pad-collapse-on-copy`，默认关闭；不进入公司记录、CSV、话术正文或上传通道。

## 不包含

- 不改变“收起为悬浮条”按钮、悬浮条布局或BOSS页面节点。
- 不新增权限、不读取剪贴板、不自动发送、不新增网络请求。
- 不改变公司身份、记录、首次时间、休息制度、沟通标记或CSV格式。

## 用户流程

1. 打开侧栏，在“打招呼话术”区看到加大的“复制话术”按钮和默认关闭的开关。
2. 打开开关，本机记住选择。
3. 点击“复制话术”；剪贴板写入成功后，右侧栏收起，页面保留悬浮条。
4. 若复制失败或设置保存失败，侧栏不收起，并提示失败原因与下一步。

## 失败与边界

- 空话术：复制按钮保持禁用。
- 剪贴板失败：显示“复制失败，请重试，或选中文字后手动复制”，不收起。
- 复制期间文本被修改：视为一次旧的复制成功，不收起，提示可再次复制。
- 开关保存失败：开关恢复原状态，在控件下方提示“开关未保存：…，请再切换一次”。
- 收起断连：复用既有结构化恢复提示，由用户明确点击“重新读取并收起”。

## 验收标准

1. 开关默认关闭；关闭时复制成功不关闭侧栏。
2. 开关开启后，复制成功收起右侧栏并保留悬浮条；效果与“收起为悬浮条”一致。
3. 复制失败、复制期间文本变化或开关保存失败时，侧栏保持打开且状态真实。
4. 开关重开侧栏后保持原选择；不写入公司CSV或话术内容。

## 数据与安全边界

- 读取：用户主动点击复制时的当前话术文本；本机开关值。
- 写入：剪贴板、本机设置键、既有话术保存与悬浮条状态。
- 不接触：BOSS聊天正文、页面业务DOM写入、公司记录格式、外部网络。
