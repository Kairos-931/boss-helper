# 休息制度提示标签（单休/单双休）

- Revision: r1
- Status: awaiting_acceptance
- 日期：2026-10-31；来源：用户产品讨论，双休不显示，单休/单双休显示提醒；用户确认标签需常驻“我的记录”。
- 执行模式：单一聊天；开发前确认（含模型建议）由用户在本聊天给出后方可实施。

## 目标与范围
电脑Chrome/BOSS，Chrome侧边栏内为用户提示公司休息制度，帮助避免投递前忽略单休/单双休。以公司为单位，与看过记录并存。

1. 只读解析BOSS页面上的休息制度信息（公司页为主；若职位详情也有可靠呈现，同规则适用）。识别不到该信息时不显示、不猜测、不把缺失当双休。
2. 识别为“双休”：不显示任何标签。页面明确写非双休排班（单休、单双休、排班轮休、大小周、轮休、轮班、月休N天等）：显示对应醒目小标签。其他无法归类的文字视为未识别；没有“工作时间及福利”区域时只保守识别原三类。
3. 常驻：当可靠识别到休息制度且当前公司已有看过记录时，把该结果与公司记录关联保存（含更新时间）；侧边栏“我的记录”列表中该公司条目持续显示对应标签。无看过记录的公司仅在当前页面区即时显示，不建新记录。
4. 已保存信息来自页面读取，仅在本机保存；不读取、不保存聊天正文或其他无关数据。仅新增一个休息制度枚举字段及更新时间，不改公司键/首次时间/查重/撤销逻辑；CSV 是否增加该列由开发前确认定稿。
5. 后续再次读到同一公司新信息时更新该字段；状态互相切换（如单双休→双休）按最新读取为准并同步列表显示。撤销公司记录时该字段随记录一并删除。
6. 不改变BOSS页面DOM、不自动发送、不弹阻断确认；识别失败不得静默当作双休或未记录。

## 验收
- 双休无标签；单休/单双休在当前页面区显示对应标签且不影响看过/未记录提示。
- 有看过记录且识别成功后，列表条目常驻标签；双休或未识别不在列表显示（或按开发前确认的弱化样式，不误导）。
- 公司记录新增字段不影响既有记录、CSV、搜索、话术；无记录公司不因此建记录。
- 枚举外文字、缺失信息不写入；页面识别失败不显示错误标签。
- 确定性验证：解析样本覆盖双休/单休/单双休/未知/缺失/更新切换/撤销删除；check/build通过；真实页面呈现与视觉效果待用户实际验收，未GUI授权不宣称生效。
