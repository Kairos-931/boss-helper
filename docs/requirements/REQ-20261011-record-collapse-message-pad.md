## 目标与行为

减少历史记录占用，在当前公司提示与我的记录之间提供一个持续保存的多行话术框，对照职位自由编辑并复制。

1. 默认按首次记录时间倒序展示最近3条；总数始终显示全部。超过3条显示“展开全部（总数）”，展开后可收起；折叠不删除记录。搜索查询全量并显示全部匹配，不受3条限制；清空搜索返回默认折叠。CSV仍导出全部。
2. 话术区标题“打招呼话术”，一个多行文本框和“复制话术”按钮；不增加模板、多个话术或AI生成功能。输入本机自动保存，不因页面切换、记录刷新或侧边栏关闭重开丢失。空文本允许保存清空，不写回复到BOSS。
3. 编辑框高度可用可见拖动区域垂直调节；保存高度，重开恢复；合理限制在80–480 CSS px并按可用视口调整，不能出现横向滚动，不改变Chrome外框宽度。
4. 复制始终取当前文本，包括保存未完成的最新输入；成功才显示已复制，失败提示可重试或手动选择复制。空文本禁用按钮。用户触发复制，优先使用现有扩展页面Clipboard API，不擅自增加clipboardRead或读取剪贴板。
5. 自动保存提供轻量保存中/已保存/失败状态，失败保留输入可重试；快速输入/延迟响应不能让旧内容覆盖最新。多窗口编辑避免静默覆盖未保存文本，最小策略由开发设计并记录。
6. 新文本和高度数据与公司记录分开存储，不改变公司键/首次时间/记录读取或CSV格式。仅本机保存，不上传，不读取BOSS聊天，不自动发送；公司页自动记录、职位手动记录及历史红色提示保持。

## 验收

- 0–3条无多余展开控件，4条以上默认3条；展开/收起、撤销和新增时总数一致。
- 搜索能找到默认被收起的记录，结果不限3条，清空恢复折叠，导出全量。
- 最新编辑文本在页面切换和侧边栏重开后保留；复制最新文本，失败不假报成功；存储失败输入不丢。
- 高度可拖动改变并持久化，有合理上下限；页面刷新不重置编辑框。
- 现有公司功能与记录数据回归通过，无新增消息发送/云端/列表自动记录行为。
