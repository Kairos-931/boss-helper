# BOSS 投递助手

一个运行在电脑 Chrome 上的 BOSS 直聘求职辅助扩展，用本地记录管理“看过哪些公司、沟通过哪些公司、收集了哪些岗位”，减少重复查看和重复沟通。

> 本地优先：记录保存在当前 Chrome 配置的本机扩展存储中，不上传到服务器；不会自动投递、自动发送消息或绕过平台验证。

当前版本：**0.22.3**  
支持环境：**Chrome 116+ / BOSS 直聘网页版**

## 功能

- **公司查重与查看记录**：公司详情页可靠识别当前公司后自动记录；职位详情页由你明确点击“标记已查看”。
- **已沟通识别**：在职位/公司详情点击“立即沟通”只建立上下文，聊天页或同页沟通弹窗真正出现你发出的消息后才标记为已沟通。
- **岗位采集**：在当前标签页开启采集，保存岗位名称、薪资、城市、经验、学历、描述、岗位标识和直达链接；同一岗位更新而不重复计数。
- **导出本次 / 导出全部**：分别导出当前采集会话的岗位和本机全部岗位，CSV 可直接用 Excel 打开。
- **悬浮球**：显示当前公司状态；支持拖拽、单击标记已查看、双击打开侧栏、历史公司红色提醒和提示音。
- **打招呼话术**：本机编辑、自动保存、复制，可选复制成功后收起侧栏。
- **数据看板**：查看公司记录、岗位数量、沟通状态和休息制度统计。
- **搜索结果辅助**：可选开启“点击职位条目即记看过”，仅在职位卡片能唯一识别公司时生效。

所有识别都以页面中明确可见的公司链接和身份为依据；遇到匿名、冲突、隐藏或无法确认的页面会显示“无法识别”，不会按名称猜测。

## 快速开始

### 方式一：加载扩展

1. 打开 Chrome，进入 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `extension` 文件夹；如果已经执行过构建，也可以选择 `dist/boss-helper`。
5. 打开 BOSS 直聘网页，点击扩展图标打开侧栏。
6. 如果页面是在扩展重新加载前打开的，先在侧栏点击“重新读取”；不需要刷新 BOSS 页面。

### 方式二：从源码构建

需要 Node.js 22 或以上：

```powershell
npm.cmd ci --ignore-scripts
npm.cmd test
npm.cmd run check
npm.cmd run build
```

构建完成后加载 `dist/boss-helper`，其中包含 `manifest.json`。扩展运行本身没有第三方依赖，`linkedom` 只用于开发测试。

> 更新扩展时建议在原来的扩展条目点击“重新加载”，不要卸载重装；卸载会删除本机记录。

## 使用说明

### 公司页与职位页

- 进入公司详情页，识别到唯一公司后会自动记录首次查看。
- 展开职位不会自动写公司记录；识别到可靠公司后，在悬浮条或侧栏明确点击“标记已查看”。
- 历史看过的公司显示红色提醒和首次查看时间；本次新记录显示绿色。
- 页面出现多个公司、推荐公司、隐藏节点或身份冲突时不会写入。

### 已沟通

- 在职位/公司详情点击“立即沟通”或“继续沟通”时，助手只记住当前公司上下文。
- 进入聊天页并真正发出消息后，才记录为“已沟通”；只打开聊天窗口不会标记。
- 不读取、不保存聊天正文；临时上下文有时效，消费后清除。
- 直接从消息列表打开旧会话时没有来源，不会凭联系人名称猜测公司。

### 岗位采集

1. 打开侧栏的“岗位采集”，点击“开始采集本页”。
2. 正常浏览岗位；已停留的岗位可先切到其他岗位再点回，让详情重新加载。
3. 侧栏/悬浮球显示本次采集数、累计数、新增/更新/未成功和最近结果。
4. 点击“导出本次”导出当前会话岗位，点击“导出全部”导出本机全部岗位。

薪资优先使用 BOSS 页面实际出现的固定详情接口数据；接口不可用时才使用明确可读的页面文本。编码字符、未知字体或冲突岗位不会伪装成完整成功。

### 数据看板

从侧栏点击“打开数据看板”，可查看：

- 已记录公司数
- 已采集岗位数（按唯一岗位去重）
- 已标记沟通数
- 尚未标记沟通数
- 沟通标记占比

看板只读取本机记录，不上传数据。

## 数据与隐私

- 数据只保存在 `chrome.storage.local` 和 `chrome.storage.session`，按当前 Chrome 配置隔离。
- 不提供账号系统、云同步、统计埋点或远程服务器。
- 不读取或保存聊天正文；沟通识别只依据当前页面是否出现本账号发出的消息。
- 薪资接口请求只发生在已开启采集的当前前台标签页，不保存 Cookie、认证令牌或完整请求 URL。
- 导出的 CSV 由你主动触发，包含公司/岗位记录，不包含聊天正文或认证信息。
- 卸载扩展会删除扩展本机存储；建议先使用“导出 CSV”留存需要的记录。

更完整的说明见 [PRIVACY.md](PRIVACY.md)。

## 权限说明

扩展只申请完成本地功能所需的权限：

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存公司记录、岗位资料、话术和本机设置 |
| `sidePanel` | 打开 Chrome 原生侧边栏 |
| `scripting` | 页面读取连接失效时，由你点击“重新读取”恢复本地读取器 |
| `webRequest` | 观察当前页真实出现的 BOSS 固定职位详情请求，用于获取正确薪资 |
| `https://www.zhipin.com/*` | 只在 BOSS 直聘网页运行 |

扩展不会申请标签页批量控制、下载管理或远程主机权限，也不会执行页面自动点击、自动投递或自动发送消息。

## 项目结构

```text
extension/          Chrome 扩展源码（manifest、侧栏、悬浮球、页面读取器）
  core/             身份解析、页面状态、岗位采集、公司记录、话术等核心模块
tests/              Node.js 确定性测试和合成 HTML fixtures
scripts/            静态检查与构建脚本
docs/               需求、技术设计、验证记录、问题台账和开发协作记录
floating-probe/     独立悬浮球试验插件
dist/               构建产物（本地生成，不提交到 Git）
```

## 开发与验证

本项目没有运行时第三方依赖，主要验证命令如下：

```powershell
npm.cmd test
npm.cmd run check
npm.cmd run build
```

- `npm.cmd test`：运行 Node 确定性测试。
- `npm.cmd run check`：检查 manifest、权限、资源引用、语法和只读路径约束。
- `npm.cmd run build`：生成 `dist/boss-helper`，并校验 27 个扩展文件逐字节一致。

当前本地验证结果：**196/196 项测试通过**，静态检查和构建通过。真实 Chrome 的页面布局、实际点击、聊天发送、Excel 打开和数据持久化仍需在用户端验收；本地测试通过不等于真实浏览器端已经生效。

## 已知边界

- 页面结构、登录状态、验证页或 BOSS 前端更新可能影响识别；无法可靠确认时不会猜测或强行记录。
- 本地记录依赖当前 Chrome 配置；换浏览器配置、卸载扩展或清理扩展数据后不会自动恢复。
- 当前不提供内置岗位筛选比较、云端同步、导入历史记录或批量自动投递。
- 本工具是个人求职效率辅助，不代表 BOSS 直聘官方；使用时应遵守平台条款和适用法律。
